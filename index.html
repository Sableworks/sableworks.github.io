RSVP Reader

Speed-reading for EPUB on PocketBook Verse Pro Color (B300). One word at a time, chapter skip, progress saved on the device. Default 150 WPM — color e-ink hard-caps at 200. Download the ZIP, then copy rsvp.app onto the reader.

  1. Download the ZIP, unzip, copy rsvp.app into applications/.
  2. Eject USB — apps often ignore new files while still connected.
  3. Launch RSVP Reader from the applications menu.

E-Ink Dictionaries

Offline English, German, French, and Spanish ↔ Polish dictionaries in .dic format — used by many e-readers for lookup while reading, not only PocketBook. Tested on PocketBook; other devices that accept the same packs can use them too. Word data from Wiktionary / FreeDict (CC BY-SA); keep that attribution if you redistribute.

  1. On PocketBook, show hidden files — Mac: Cmd+Shift+.; Windows: File Explorer → View → Hidden items.
  2. Copy the .dic files into system/dictionaries (the system folder is hidden). Other brands: that device’s dictionary folder.
  3. Eject USB, then pick the dictionary on the reader.
